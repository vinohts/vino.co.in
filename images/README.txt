This folder is ready for any images you want to add (profile photo, favicon, blog thumbnails, etc.).

The current design doesn't use any image files — the orbit graphic in the hero section is
drawn live with inline SVG + JavaScript (see js/script.js), so there was nothing to extract
into this folder yet.

To add an image:
1. Drop the file in here, e.g. images/profile.jpg
2. Reference it in index.html like: <img src="images/profile.jpg" alt="...">
